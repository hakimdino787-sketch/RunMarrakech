# RUN MARRAKECH

A production-oriented Unity 6 endless runner for Android.

## Vision
RUN MARRAKECH is an original 3D endless runner inspired by the fast lane-switching genre, with its own Marrakech identity, characters, environments, audio and progression.

## Core loop
- 3 lanes
- Swipe left/right to change lanes
- Swipe up to jump
- Swipe down to slide
- Obstacles and moving traffic
- Coins and power-ups
- Increasing speed and difficulty
- Distance, score and high score
- Mobile-first performance

## Repository status
This repository contains the source foundation and game architecture. Unity Editor is required to open, author, test and build the final Android game.
