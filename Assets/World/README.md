# RUN MARRAKECH — 3D World Production

## Visual direction
The game world is an original stylized-realistic Marrakech runner:
- Warm ochre/pink plaster architecture
- Narrow market streets and riad-inspired facades
- Palm trees and Moroccan street details
- Marrakech-inspired signage and props
- Three-lane runner route
- Strong depth, lighting and atmospheric perspective

## Production rules
- Use original or properly licensed models/textures.
- Keep mobile draw calls and texture memory under control.
- Use LODs for buildings, props and vegetation.
- Prefer baked/static lighting where practical.
- Use texture atlases for repeated props.
- Keep the player route readable at high speed.
