# RUN MARRAKECH — Unity 6 Bootstrap

This folder contains an Editor-only bootstrap utility. Open the repository as a Unity 6 project, then use **Tools > Run Marrakech > Create Starter Scene**.

The utility creates a clean test scene with:
- 3-lane road
- player runner with CharacterController and gameplay components
- follow camera
- GameManager / RunSession
- directional light and simple mobile-friendly materials
- lane markers
- sample coins, barriers and power-up objects
- Canvas HUD

It intentionally creates lightweight primitive placeholders so the project can be compiled and tested before final GLB/FBX art is imported.
